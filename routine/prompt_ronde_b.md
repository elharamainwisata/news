== SUMBER UTAMA: HAJI.GO.ID (Kementerian Haji dan Umrah RI) & SUBDOMAINNYA ==
haji.go.id adalah aplikasi React: WebFetch ke halaman beritanya akan KOSONG. Ambil data lewat API JSON dengan curl:
- Daftar berita terbaru: curl -s "https://haji.go.id/api/news?page=1&limit=20" -> data.news[] berisi title, content (teks lengkap), slug, thumbnail (foto resmi), publishDate (UTC), category (mis. - Detail satu berita: curl -s "https://haji.go.id/api/news/<slug>" -> data.{title, content, thumbnail, publishDate, referenceUrl}.
- Link sumber yang dipasang di artikel = referenceUrl (format https://haji.go.id/berita/<slug>).
- Subdomain berguna: ppid.haji.go.id (PPID Kemenhaj; halaman HTML biasa) - https://ppid.haji.go.id/informasi?jenis_informasi=serta_merta (informasi mendesak), https://ppid.haji.go.id/informasi?jenis_informasi=berkala , https://ppid.haji.go.id/melawan-hoaks (klarifikasi hoaks resmi - bagus untuk artikel peringatan/klarifikasi).
